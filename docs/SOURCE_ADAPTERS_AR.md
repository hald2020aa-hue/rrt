# محرك المصادر المرن — ملاحظات تقنية

## الأنواع المبدئية

1. Madara / WordPress Manga: `.page-item-detail`, `.wp-manga-chapter`, `.reading-content img`.
2. Themesia: `.listupd .bs`, `.eph-num a`, `.readerarea img`.
3. HTML عام: محددات CSS مخصصة لكل موقع.

## خطوات إضافة موقع

- افتح `المصادر` ثم `إضافة موقع جديد`.
- أدخل الاسم والرابط `https://...`.
- حدد خيار 18+ للمصادر المناسبة. الإعداد وحده لا يجلب المحتوى ولا يحدد العمر.
- جرّب `كشف تلقائي`؛ إذا فشل بسبب حماية الموقع، استخدم `حفظ يدوي` ثم `تعديل` لضبط محددات CSS.
- اضغط `اختبار` لقياس عدد البطاقات. العدد >0 يعني اكتشاف بطاقات، وليس إثبات اكتمال الفصول والصور.
- افتح فهرس المصدر ثم عملًا ثم فصلًا. افحص الصور والتنزيل قبل اعتباره متوافقًا.

## أسباب عدم التوافق

- JavaScript مطلوب لعرض HTML بعد التحميل
- API بمفاتيح أو بنية خاصة
- HTTP 403/429/503 أو CAPTCHA
- DOM مختلف أو صور مؤجلة `lazy-loaded`
- مصادر الفصل أو الصور تتطلب تسجيل الدخول

لا تحاول تعطيل وسائل الحماية؛ اطلب دعمًا رسميًا من الموقع أو اعتمد واجهة مسموحًا بها.
