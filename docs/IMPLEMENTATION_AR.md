# RRT Neon Reader: التنفيذ والمحدوديات

تم فحص حزمتَي استخراج التطبيق الأصلي: `jadx-sources.zip` (ملفات Java مسترجعة) و`apktool-output.zip` (Smali وموارد). الاستنتاج: نسخ الملفات المستخرجة حرفيًا لن يعيد مشروع Kotlin/Gradle أصليًا، لذلك بني المشروع الجديد بشكل مستقل بدون نسخ أو تجاوز مكونات الترخيص في التطبيق الأصلي.

## ما تم برمجته

- تطبيق Android مكتوب بلغة Kotlin؛ الواجهات عربية داكنة ونيون، مناسبة للشاشات العادية والقابلة للطي.
- محرك HTML قابل للتهيئة: عنوان HTTPS، مسار الفهرس، البحث، محددات CSS للعمل والعنوان والرابط والغلاف والفصول والصور.
- دعم مصادر 18+ بشكل اختياري؛ لا يوجد حظر على أساس اسم الموقع أو تصنيفه وحده. الافتراضي: إخفاؤها.
- استيراد مصادر JSON ولصق إعدادات جديدة وتصدير الإعدادات إلى الحافظة.
- فهرس المصادر والبحث داخل مصدر والبحث العام والمكتبة والمفضلة.
- القارئ الرأسي باستخدام RecyclerView وGlide والتحميل التدريجي للصور.
- تنزيل صور الفصل مع Referer وUser-Agent في تخزين التطبيق، وقراءتها محليًا لاحقًا.
- GitHub Actions لبناء debug APK وإتاحته في Artifacts.

## ما يحتاج اختبارًا وتطويرًا بعد تشغيل الإصدار الأول

- لم يُختبر التطبيق على جهاز Android فعلي أو بتشغيل Gradle داخل هذه البيئة. تأكد من نتيجة أول GitHub Actions، ثم أرسل سجل الخطأ في حال الفشل.
- دعم مواقع JavaScript/API/WordPress المخصصة: يحتاج موصلات إضافية واختبارات فعلية على كل موقع.
- لا يتجاوز تسجيل الدخول أو CAPTCHAs أو Cloudflare أو القيود التقنية والقانونية للموقع.
- تنزيل الفصول حاليًا يعمل أثناء بقاء عملية التطبيق نشطة، ولا يدعم قائمة انتظار تستمر في الخلفية بعد أن يقتل النظام العملية.
- لا يمكن تحديد جودة صورة غير متاحة في الموقع، ولا يتم استعادة الصور المحمية.
- خاصية `nextSelector` مخزنة لكنها غير مستخدمة بعد لتنفيذ التصفح متعدد الصفحات للفهرس.
- يوصى لاحقًا بإضافة اختبارات الوحدة والعمل على تحسين تجربة الأخطاء والتعامل مع الفصول الكبيرة.

## خطوات الاختبار

1. بعد الحصول على APK من GitHub، فعّل مصادر 18+ من الإعدادات عند الحاجة.
2. أضف قالب Madara وعدّل الرابط إلى موقع تسمح سياساته بالوصول لصفحاته.
3. افتح الفهرس، وتحقق من العناوين والروابط وصور الأغلفة.
4. جرّب بحثًا ثم افتح عملًا واختر فصلًا.
5. جرّب تنزيل فصل واحد، ثم افتحه من «التنزيلات» مع فصل الإنترنت.

### ملاحظة أخلاقية وقانونية

يستخدم التطبيق فقط للوصول إلى مصادر متاحة ومحتوى مسموح، ويلزم احترام حقوق النشر وشروط الخدمة. لن ننسخ مكونات حماية المصدر الأصلي أو نلغي تراخيصه.
